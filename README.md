# IAI Survivors

**IAI Survivors** est un jeu de survie/combat développé en plusieurs versions cross-platform dans le cadre du projet IAI.

## Versions

| Version | Technologie | Description |
|---------|-------------|-------------|
| `web-vite` | JavaScript / Vite | Version web moderne avec build tooling Vite |
| `flutter` | Flutter (Dart) | Application mobile avec flutter_bloc & Hive |
| `vanilla-js` | JavaScript (Vanilla) | Version web native sans framework |
| `love2d` | Lua / LÖVE2D | Version desktop en pixel-art 2D |
